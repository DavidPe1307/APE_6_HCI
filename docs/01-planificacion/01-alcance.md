# 01 · Contexto y alcance de la evaluación

| Elemento | Definición |
|---|---|
| Prototipo evaluado | **TutoUTA v1**, prototipo interactivo en Figma de una app de agendamiento de tutorías académicas (enlace en el README) |
| Rol de usuario probado | **Estudiante** universitario |
| Flujo principal | Reservar una tutoría, consultarla, cambiar su hora, cancelarla y configurar un recordatorio |
| Dispositivo | Móvil 390×844 en modo presentación |
| Participantes | 5 estudiantes de distintas carreras (P01–P05) + 1 piloto (P00) |
| Duración | ~20 min por sesión |
| Tipo de estudio | Formativo (n = 5): descubrir problemas, no demostrar que la app funciona |

## Fuera de alcance
- Backend real, base de datos y autenticación real.
- Roles de docente tutor y administrador.
- Notificaciones push reales, pagos y calendario externo.
- Rendimiento de red y pruebas en múltiples dispositivos.

## Supuestos
- El prototipo se reinicia con «Reiniciar demo» (Ajustes) o recargando el enlace entre participantes.
- Los participantes no han visto antes el prototipo.
