# 03 · Escenario y tareas (T1–T5)

## Escenario (se lee al participante)
> «Tienes una evaluación de Cálculo la próxima semana y quieres ayuda de un tutor. Vas a usar esta aplicación para organizarte. Piensa en voz alta mientras la usas. Recuerda que evaluamos la aplicación, no a ti.»

## Tarjetas de tarea (una por hoja; no revelan botones, menús ni pasos)

| ID | Tarjeta para el participante | Criterio de éxito | Tiempo meta | Cubre |
|---|---|---|---|---|
| T1 | «Consigue una tutoría de Cálculo para esta semana.» | Se muestra la confirmación con fecha y hora | ≤ 90 s | O1 · flujo principal |
| T2 | «Comprueba qué día y a qué hora quedó tu tutoría.» | Dice correctamente fecha y hora | ≤ 30 s | O1 · visibilidad del estado |
| T3 | «Te das cuenta de que a esa hora tienes clase. Haz que tu tutoría sea en la tarde.» | La reserva muestra un horario de tarde | ≤ 60 s | O2 · corrección de error |
| T4 | «Ya no podrás asistir a esa tutoría. Haz que deje de estar agendada.» | La reserva ya no aparece como activa | ≤ 45 s | O3 · control y libertad |
| T5 | «Quieres recibir avisos antes de tus tutorías. Ajusta las notificaciones de la app como prefieras.» | Queda activo un recordatorio | ≤ 60 s | O3 · personalización |

## Reglas verificadas
- [x] Una sola meta observable por tarea, con criterio de éxito.
- [x] Ninguna tarjeta nombra botones, menús o pasos.
- [x] De simple a compleja; T3 = corrección de error; T4 = cancelar.
- [x] Orden fijo T1→T5 para todos los participantes.

> Si el prototipo no permite alguna tarea tal cual, se ajusta en la bitácora del piloto (Fase 2), no durante P01–P05.
